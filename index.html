British Council short course · 3 hours · hands-on

Physics-informed machine learning for civil engineers

Build a physics-informed neural network from scratch in PyTorch, on one cantilever beam you can check by hand: a simple model of an embedded retaining wall.

  • 180 min, two hands-on blocks
  • 4 Colab notebooks with self-checks
  • Runs on the free Colab CPU
  • Prerequisite: some Python
Slides & notebooks Check your setup

How the course works

One beam, from data-only fit to inverse problem

A cantilever under a uniform load q, and later a point load P at mid-span. It has an exact solution, so every error you see is a real error.

01

Why physics

A data-only network fits the sensors well and still gets the bending moment wrong.

02

Forward PINN

Write the physics and boundary losses yourself and check the result against statics.

03

Inverse PINN

Recover the unknown load from noisy deflection readings. The load becomes a trainable parameter.

04

When it fails

Point loads, spectral bias, domain decomposition, the limits of identifiability, and when to reach for neural operators.

Schedule

Three hours, nine blocks

Times are from the start of the session.

  1. 0:00Why physics-informed ML?N0

    Engineering decisions that need many runs, four challenges for data-only models, where bias enters, the PgNN / PINN / PeNN spectrum

  2. 0:15How networks learn and differentiateN0

    Forward pass, backpropagation, derivatives with respect to the input, finite differences versus autodiff, activations

  3. 0:30Anatomy of a PINNN1

    The workflow, collocation points and boundary terms, non-dimensionalisation, loss weights

  4. 0:50Hands-on 1: the forward PINNN1

    Four TODOs, checked against statics

  5. 1:25Break
  6. 1:35Inverse problems: back-analysis of the loadN2

    What is unknown on a real wall, the inverse loss, PINN versus data-only

  7. 1:50Hands-on 2: the inverse PINNN2

    Recover the load from sixteen noisy readings, then a class experiment on sensors and noise

  8. 2:20Failure modes of PINNs, and remediesN3

    Loss balancing, self-adaptive PINNs, adaptive sampling, hard constraints, weak form; the point load, spectral bias and domain decomposition; why neural operators

  9. 2:50Wrap-up

    What we learned, and when to use a PINN

Before the session · 5 minutes

Check your setup

Everything runs in the browser on Google Colab. Nothing to install.

  1. Sign in to Google

    Any Google account works. Colab is free.

  2. Open notebook N0 in Colab

    Use the button in Slides & notebooks, then choose Runtime → Run all. If it runs to the end without errors, you are ready.

  3. Optional: a GPU

    Runtime → Change runtime type. Not needed: every notebook is designed for the free CPU.

Prefer your own laptop? Python 3.10 or newer, then pip install torch numpy matplotlib jupyter.
