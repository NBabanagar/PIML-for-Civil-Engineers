One beam, from data-only fit to inverse problem

A cantilever under a uniform load q, and later a point load P at mid-span. It has an exact solution, so every error you see is a real error.

ℒ = ℒdata + λ ℒphysics + ℒsupports

ℒphysics = mean over collocation points of ( EI w⁗(x) − q )²

One loss, three parts. The network is penalised for missing the sensor readings, for breaking the beam equation at the collocation points, and for violating the supports: no deflection or rotation at the wall, no moment or shear at the free tip.

Course notebooks

Three notebooks, all in Google Colab, with nothing to install. Each opens in your own account: use File → Save a copy in Drive to keep your edits. N0 is shown on screen during the course; N1 and N2 are the two hands-on sessions.

Check your setup

Do this before the session. It takes about five minutes, all in the browser on Google Colab, with nothing to install.

  1. Sign in to Google

    Any Google account works. Colab is free.

  2. Open the setup check in Colab

    Click the button, then choose Runtime → Run all. If Colab warns that the notebook is from GitHub, click Run anyway. It checks PyTorch, NumPy and Matplotlib, tests automatic differentiation up to the fourth derivative, and trains a tiny physics-informed network.

    Open setup check in Colab

  3. Look for the last line

    It should say You are all set up. If a line shows ✗, follow the hint printed underneath, or send a screenshot of the output to the instructor.

  4. Optional: a GPU

    Runtime → Change runtime type. Not needed: every notebook is designed for the free CPU.
