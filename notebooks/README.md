# Notebooks

Put the course notebooks here, with exactly these file names (the website links to them):

- `N0_student.ipynb`
- `N1_student.ipynb`
- `N2_student.ipynb`
- `N3_student.ipynb`

After the session, add `N0_solution.ipynb` … `N3_solution.ipynb` and set `showSolutions: true` in `index.html`.

If you use different names, change the `NOTEBOOKS` list near the bottom of `index.html` to match.
