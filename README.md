# Physics-informed machine learning for civil engineers

British Council short course (3 hours, hands-on) by Nandeesh Babanagar, University of Cambridge.

Course website: https://nbabanagar.github.io/PIML-for-Civil-Engineers/

## Contents

| Folder | What is in it |
|---|---|
| `index.html` | The course website |
| `slides/` | Lecture slides (PDF) |
| `notebooks/` | Colab notebooks N0–N3 (student versions; solutions after the session) |
| `assets/img/` | Images used on the website |

## Running the notebooks

Open a notebook from the website with **Open in Colab**, then *Runtime → Run all*.
To run locally: Python 3.10+, then `pip install torch numpy matplotlib jupyter`.
